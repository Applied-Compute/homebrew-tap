# Applied Compute Homebrew tap

Install Applied Compute packages with [Homebrew](https://brew.sh).

## Add the tap

With Homebrew installed, run:

```sh
brew tap Applied-Compute/tap
```

Then install a package from the sections below.

## Packages

### Shift

[Shift](https://shift.ac) connects your coding agents to the Applied Compute router.
Available on macOS and Linux, with ARM64 or Intel/AMD64.

```sh
brew install acshift
```

Then connect your coding agents:

```sh
acshift install
```

You can also install Shift and add the tap in one command:

```sh
brew install Applied-Compute/tap/acshift
```
